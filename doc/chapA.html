A Errata to the literature

While implementing the constructions of [HR05] and [HR10], we noticed a few misprints and small omissions. We list them here, together with the corrections used in ClassicalMaximals, in the hope that they are useful to other readers. None of them affects the overall approach of these papers.

We use the notation of the respective paper; in addition, E_i,j denotes the matrix with a 1 in position (i, j) and zeros elsewhere.

A.1 Constructing maximal subgroups of classical groups

These remarks concern [HR05].

Proposition 4.5

The direct product with SU(d - 2k, q) should be formed with SL(k, q^2) rather than GL(k, q^2): for A ∈ GL(k, q^2), the matrix Diag[A, I_d - 2k, J A^-* J] has determinant det(A)^1 - q. The diagonal matrix added at the end of the proof supplies the remaining elements.

For odd q, the second transvection is T_2 := I_d + E_d,d-k - E_k+1,1, and for d - 2k = 1 one takes (λ_1, λ_2, λ_3) = (1, -μ, μ^q). With the signs as printed, T_2 does not preserve F.

For even q and d - 2k = 1, λ_1 must satisfy λ_1 + λ_1^q = 1, so one takes (λ_1, λ_2, λ_3) = (α, 1, 1) with α + α^q = 1, as in Proposition 4.6. A primitive element ζ need not satisfy this; for example, it fails for q = 8 when ζ is a root of the Conway polynomial.

In the final diagonal matrix, the entries in rows d and d - k are ζ^-q and ζ^q; with ζ^-p and ζ^p, the matrix preserves F only if q = p.

Proposition 5.4

The matrix C has determinant (-1)^m. For odd m, replace C by Diag[-1, 1, ..., 1] ⋅ C.

Proposition 5.5

For d = 2, rows 1, 2 and rows d - 1, d coincide, so D is not well defined. The matrix D := Diag[ζ^q+1, 1, ..., 1, ζ^-q-1] works for every even d.

Lemma 6.1

The group ⟨ A, B ⟩ ≅ ⟨ ω, ν_q ⟩ is the subgroup of Γ L(1, q^s) of GF(q)-linear maps, of order s (q^s - 1); it equals Γ L(1, q^s) only if q is prime. The subsequent constructions need exactly this subgroup, so they are not affected.

Proposition 8.5

The matrix D is a scalar multiple of a similarity of F with multiplier -ζ^-(q+1). If q ≡ 3 mod 4, this multiplier is a square in GF(q), so D ∈ ⟨ C ⟩ Sp(d, q) and ⟨ A, B, C, D ⟩ has index 2 in G; the smallest example is SU(8, 3). A suitable choice is D := Diag[ζ^m, ..., ζ^m, ζ^-qm, ..., ζ^-qm] with m := (q + 1) / (q + 1, d/2): then ζ^-m D is a similarity of F with multiplier ζ^-m(q+1), which is a non-square in GF(q) as m is odd when c ≠ 1, and det(D) = 1.

Proposition 10.4

In the structure of G / (G ∩ Z), PSL(m, q) should read PSU(m, q), and case (a) occurs for q ≡ 1 mod 4 rather than q ≡ 3 mod 4; compare [BHR13, Table 2.10].

Proposition 11.2

The structure should read G_ε ≅ Z. PSO^ε(d, q).(d, 2), in line with Propositions 8.4 and 11.1. For even d, Z ∩ SO^ε(d, q) = ⟨ -I_d ⟩, and |G_ε| = (q - 1, d) | SO^ε(d, q)|; compare [BHR13, Table 2.11].

The elements W_ε of Proposition 8.4 are constructed in SU(d, q), using (q + 1, d). For SL(d, q) they need an analogous construction with (q - 1, d) in place of (q + 1, d).

A.2 Constructing maximal subgroups of orthogonal groups

These remarks concern [HR10].

Lemma 4.2

In the case d even, k = m - 1 > 1 and ε = +, the matrix H_7 should read I + E_k+2,1 - E_d,d-k-1, analogous to H_6. The printed I + E_k+2,1 - E_d-k-1,1 does not preserve Q^+_d.

Lemma 4.3

For odd q and k > 1, the matrix H_6 should read S^ε_1_k ⊕ S^ε_2_d-k, as for H_5, rather than S^ε_k ⊕ S^ε_d-k.
