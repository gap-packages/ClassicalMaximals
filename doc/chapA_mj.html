A Errata to the literature

While implementing the constructions of [HR05] and [HR10], we noticed a few misprints and small omissions. We list them here, together with the corrections used in ClassicalMaximals, in the hope that they are useful to other readers. None of them affects the overall approach of these papers.

We use the notation of the respective paper; in addition, \(E_{i,j}\) denotes the matrix with a \(1\) in position \((i, j)\) and zeros elsewhere.

A.1 Constructing maximal subgroups of classical groups

These remarks concern [HR05].

Proposition 4.5

The direct product with \({\rm SU}(d - 2k, q)\) should be formed with \({\rm SL}(k, q^2)\) rather than \({\rm GL}(k, q^2)\): for \(A \in {\rm GL}(k, q^2)\), the matrix \({\rm Diag}[A, I_{d - 2k}, J A^{-*} J]\) has determinant \(\det(A)^{1 - q}\). The diagonal matrix added at the end of the proof supplies the remaining elements.

For odd \(q\), the second transvection is \(T_2 := I_d + E_{d,d-k} - E_{k+1,1}\), and for \(d - 2k = 1\) one takes \((\lambda_1, \lambda_2, \lambda_3) = (1, -\mu, \mu^q)\). With the signs as printed, \(T_2\) does not preserve \(F\).

For even \(q\) and \(d - 2k = 1\), \(\lambda_1\) must satisfy \(\lambda_1 + \lambda_1^q = 1\), so one takes \((\lambda_1, \lambda_2, \lambda_3) = (\alpha, 1, 1)\) with \(\alpha + \alpha^q = 1\), as in Proposition 4.6. A primitive element \(\zeta\) need not satisfy this; for example, it fails for \(q = 8\) when \(\zeta\) is a root of the Conway polynomial.

In the final diagonal matrix, the entries in rows \(d\) and \(d - k\) are \(\zeta^{-q}\) and \(\zeta^q\); with \(\zeta^{-p}\) and \(\zeta^p\), the matrix preserves \(F\) only if \(q = p\).

Proposition 5.4

The matrix \(C\) has determinant \((-1)^m\). For odd \(m\), replace \(C\) by \({\rm Diag}[-1, 1, \ldots, 1] \cdot C\).

Proposition 5.5

For \(d = 2\), rows \(1, 2\) and rows \(d - 1, d\) coincide, so \(D\) is not well defined. The matrix \(D := {\rm Diag}[\zeta^{q+1}, 1, \ldots, 1, \zeta^{-q-1}]\) works for every even \(d\).

Lemma 6.1

The group \(\langle A, B \rangle \cong \langle \omega, \nu_q \rangle\) is the subgroup of \(\Gamma{\rm L}(1, q^s)\) of \({\rm GF}(q)\)-linear maps, of order \(s (q^s - 1)\); it equals \(\Gamma{\rm L}(1, q^s)\) only if \(q\) is prime. The subsequent constructions need exactly this subgroup, so they are not affected.

Proposition 8.5

The matrix \(D\) is a scalar multiple of a similarity of \(F\) with multiplier \(-\zeta^{-(q+1)}\). If \(q \equiv 3 \bmod 4\), this multiplier is a square in \({\rm GF}(q)\), so \(D \in \langle C \rangle {\rm Sp}(d, q)\) and \(\langle A, B, C, D \rangle\) has index \(2\) in \(G\); the smallest example is \({\rm SU}(8, 3)\). A suitable choice is \(D := {\rm Diag}[\zeta^m, \ldots, \zeta^m, \zeta^{-qm}, \ldots, \zeta^{-qm}]\) with \(m := (q + 1) / (q + 1, d/2)\): then \(\zeta^{-m} D\) is a similarity of \(F\) with multiplier \(\zeta^{-m(q+1)}\), which is a non-square in \({\rm GF}(q)\) as \(m\) is odd when \(c \neq 1\), and \(\det(D) = 1\).

Proposition 10.4

In the structure of \(G / (G \cap Z)\), \({\rm PSL}(m, q)\) should read \({\rm PSU}(m, q)\), and case (a) occurs for \(q \equiv 1 \bmod 4\) rather than \(q \equiv 3 \bmod 4\); compare [BHR13, Table 2.10].

Proposition 11.2

The structure should read \(G_\varepsilon \cong Z.{\rm PSO}^\varepsilon(d, q).(d, 2)\), in line with Propositions 8.4 and 11.1. For even \(d\), \(Z \cap {\rm SO}^\varepsilon(d, q) = \langle -I_d \rangle\), and \(|G_\varepsilon| = (q - 1, d) |{\rm SO}^\varepsilon(d, q)|\); compare [BHR13, Table 2.11].

The elements \(W_\varepsilon\) of Proposition 8.4 are constructed in \({\rm SU}(d, q)\), using \((q + 1, d)\). For \({\rm SL}(d, q)\) they need an analogous construction with \((q - 1, d)\) in place of \((q + 1, d)\).

A.2 Constructing maximal subgroups of orthogonal groups

These remarks concern [HR10].

Lemma 4.2

In the case \(d\) even, \(k = m - 1 > 1\) and \(\varepsilon = +\), the matrix \(H_7\) should read \(I + E_{k+2,1} - E_{d,d-k-1}\), analogous to \(H_6\). The printed \(I + E_{k+2,1} - E_{d-k-1,1}\) does not preserve \(Q^+_d\).

Lemma 4.3

For odd \(q\) and \(k > 1\), the matrix \(H_6\) should read \(S^{\varepsilon_1}_k \oplus S^{\varepsilon_2}_{d-k}\), as for \(H_5\), rather than \(S^\varepsilon_k \oplus S^\varepsilon_{d-k}\).
